# Contribuir

1. Lee `IMPLEMENTATION_STATUS.md` y la especificación de origen.
2. Crea una rama corta `feat/*`, `fix/*`, `docs/*` o `chore/*`.
3. Escribe código en inglés y textos de producto traducibles.
4. Añade tests y documentación en el mismo cambio.
5. Ejecuta `pnpm verify`.
6. Usa Conventional Commits y no incluyas secretos ni datos reales.

Las decisiones arquitectónicas relevantes requieren un ADR en `docs/adr`.
