# Glosario

| Término          | Definición                                                                          |
| ---------------- | ----------------------------------------------------------------------------------- |
| Material         | Producto, pieza, equipo, componente o consumible gobernado como dato maestro        |
| Solicitud        | Petición de creación, actualización o ampliación de un material                     |
| Documento fuente | Archivo que aporta información y evidencia                                          |
| Atributo         | Propiedad tipada de un material                                                     |
| Sugerencia       | Valor propuesto por reglas o IA                                                     |
| Confianza        | Estimación normalizada de 0 a 1; no sustituye una decisión humana                   |
| Evidencia        | Fragmento o regla que respalda una sugerencia                                       |
| Categoría        | Clase que determina el esquema de atributos                                         |
| Duplicado        | Material existente que puede representar la misma entidad                           |
| Workflow         | Máquina de estados con transiciones autorizadas                                     |
| Sincronización   | Validación y envío de datos al simulador o endpoint SAP                             |
| Data Steward     | Responsable humano de calidad y gobierno                                            |
| UAT              | Prueba de aceptación ejecutada por usuarios de negocio                              |
| Regla de calidad | AST determinista y seguro que valida uno o varios campos                            |
| Run de IA        | Ejecución trazada de un proveedor o pipeline                                        |
| Puerto           | Contrato estable que desacopla aplicación e infraestructura                         |
| Adaptador        | Implementación de un puerto para memoria, simulador o servicio externo              |
| Modo demo        | Recorrido completo con datos y servicios simulados, siempre indicado                |
| Modo real        | Integración habilitada explícitamente con endpoint, identidad y health verificables |
