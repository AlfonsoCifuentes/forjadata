# Datos demo

Los datos son sintéticos y deterministas:

- `pnpm db:seed` crea el dataset rápido (250 materiales).
- `DEMO_SEED_SIZE=large pnpm db:seed` crea 50.000 materiales y 1.500 solicitudes.
- `pnpm demo:reset` restablece el motor demo/API cuando está en ejecución.

Las fichas y marcas del recorrido son ejemplos creados para Forjadata. No se incluyen documentos
propietarios ni datos personales reales.
